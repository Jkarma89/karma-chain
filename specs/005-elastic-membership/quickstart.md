## A · 分家前后生成物逐字节相同（**先做这个**）

```bash
# 分家**之前**，把 10 项生成物的指纹留下来
npm run render:check
sha256sum blockchain/nodes/*/*.json blockchain/nodes/*/rpc-proxy.conf \
          docker/compose/*.yml blockchain/genesis/*.json docs/protocol-parameters.md \
          > /tmp/before.sha256

# 分家之后
npm run render && sha256sum -c /tmp/before.sha256
```

**期望**：**全部 OK**。任何一项变了都说明这次"搬家"顺手改了行为 ——
而本期承诺的是**只搬家**（FR-007）。

> 这是本期最强的一条不回归判据。比任何"我检查过了"都强，
> 也比逐个读 diff 可靠 —— 10 项生成物加起来几千行。

## E · 加一台机器进拓扑，链一秒都不停（**需五台**）

```bash
# 1. 在一台机器上改部署描述、渲染、推送（渲染只做一次 —— Ubuntu 宿主没有 npm）
#    见 docs/devnet.md §9.3.1 的同一模型

# 2. 五台既有机器各自：
git pull
# 只重建受影响的容器（节点不动）
docker inspect --format '{{.Name}} {{.Created}} {{.State.StartedAt}}' karmachain-<本机节点>   # 改动前
# …重建…
docker inspect --format '{{.Name}} {{.Created}} {{.State.StartedAt}}' karmachain-<本机节点>   # 改动后，必须逐字符相同
```

**同时**在整个过程中每 30 秒发一笔交易，连续 10 分钟：**全部确认、零次 5xx**（SC-002）。

**期望**：stamp 六项逐字节不变、**零个节点退出 12**、创世哈希不变、
既有节点容器的 `Created`/`StartedAt` **逐字符相同**。

> **判据是时刻，不是状态**（004 学到的）：若有人手滑漏了服务名把节点一起重建，
> 容器仍然"在跑"，而 `StartedAt` 已经变了。


| 步 | 期望 |

| 退出后 | 集合数 −1，链持续出块，该节点**不被**报成故障节点 |
